Student Expense Tracker
📌 Project Overview

The Student Expense Tracker is a Python-based desktop application designed to help students manage and track their daily expenses efficiently. It provides a simple and user-friendly graphical interface to record, view, and manage expenses.

The application uses Tkinter for the graphical user interface and SQLite3 for storing expense records in a local database.

✨ Features
Add Expenses: Record daily expenses with details such as amount, category, date, and description.
View Expenses: Display all recorded expenses in an organized format.
Update Expenses: Modify existing expense records.
Delete Expenses: Remove unwanted expense records.
Expense Management: Organize expenses based on categories.
Data Storage: Store expense information securely in a local SQLite database.
User-Friendly Interface: Simple and interactive GUI built using Tkinter.

⚙️ Installation and Setup
1. Clone the Repository
bash
git clone https://github.com/your-username/student-expense-tracker.git

2. Navigate to the Project Directory
bash
cd student-expense-tracker

3. Install Python

Make sure Python 3 is installed on your system.

Download Python from: https://www.python.org/downloads/

4. Install Dependencies

Tkinter and SQLite3 are included with most standard Python installations.

If necessary, install Tkinter separately according to your operating system.

5. Run the Application
bash
python main.py

🗄️ Database Information

The application uses SQLite3 to store expense records locally.

The database maintains expense information such as:

Expense ID
Expense Amount
Expense Category
Expense Date
Expense Description

SQLite3 does not require a separate database server, making it suitable for a lightweight desktop application.
